## 2. Dataset Nature & Ethical Disclaimer
> **IMPORTANT NOTE:**  
> The AI4I 2020 dataset consists of **10,000 synthetic observations** mathematically modeled to reflect real-world industrial milling machine behavior. The data reflects realistic physics-based relationships (e.g., power calculations, heat dissipation balance, overstrain formulas, and tool wear progression) designed specifically as a benchmark for predictive maintenance algorithms.  
> It is **not** direct streaming telemetry from active industrial shop-floor machinery. Predictions produced from this dataset are for educational and academic decision-support purposes and must **not** be deployed for safety-critical hardware shutdown or life-critical machinery controls.

## 4. Complete Schema & Leakage Boundary Specification

The dataset contains **14 columns** and **10,000 records**:

| Column Name | Data Type | Role in Pipeline | Description / Physics Grounding |
|---|---|---|---|
| `UDI` | Integer (1..10000) | **Excluded** (Identifier Leakage) | Unique row index. Must never be used as a predictor. |
| `Product ID` | String | **Excluded** (Identifier Leakage) | Serial code consisting of Type letter + serial number. |
| `Type` | Categorical (`L`, `M`, `H`) | **Predictor Feature** | Product quality variant: Low (50%), Medium (30%), High (20%). |
| `Air temperature [K]` | Float | **Predictor Feature** | Ambient air temperature generated by random walk (~300 K). |
| `Process temperature [K]` | Float | **Predictor Feature** | Process temperature (~Air temp + 10 K). |
| `Rotational speed [rpm]` | Integer | **Predictor Feature** | Spindle speed calculated from a 2860 W motor base with noise. |
| `Torque [Nm]` | Float | **Predictor Feature** | Motor torque normally distributed around 40 Nm (std: 10 Nm). |
| `Tool wear [min]` | Integer | **Predictor Feature** | Accumulated cutting tool operation time. |
| `Machine failure` | Binary (0 / 1) | **Target Variable** | Overall machine failure indicator (0 = Normal, 1 = Failure). |
| `TWF` | Binary (0 / 1) | **Excluded** (Target Leakage) | Tool Wear Failure mode indicator. |
| `HDF` | Binary (0 / 1) | **Excluded** (Target Leakage) | Heat Dissipation Failure mode indicator. |
| `PWF` | Binary (0 / 1) | **Excluded** (Target Leakage) | Power Failure mode indicator. |
| `OSF` | Binary (0 / 1) | **Excluded** (Target Leakage) | Overstrain Failure mode indicator. |
| `RNF` | Binary (0 / 1) | **Excluded** (Target Leakage) | Random Failure mode indicator. |

### Strict Leakage Rules for Modeling
When predicting `Machine failure`, all sub-failure mode indicators (`TWF`, `HDF`, `PWF`, `OSF`, `RNF`) as well as index columns (`UDI`, `Product ID`) are **strictly excluded**. Using sub-failure indicators to predict overall failure causes 100% artificial label leakage, rendering the model useless for true proactive condition monitoring.
